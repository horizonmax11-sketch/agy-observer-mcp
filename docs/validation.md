# 验证范围

独立包的验证命令：`python -m unittest discover -s tests -v`。

2026-10-23 发布前本地结果：Windows Python3.10共24项，23通过、1项因无symlink创建权限跳过；WSL Python3.11共24项全部通过。wheel构建成功，静态页面与许可证打包已检查；模拟页面已在浏览器中实际显示。这里只报告观察到的本地结果，远端CI需以Actions实际状态为准。

测试使用合成提示、合成响应和本地Python父子进程；stdio握手测试强制`AGY_OBSERVER_ENABLED=0`，并确认拒绝的run调用没有产生历史目录。不会通过测试启动官方CLI。

覆盖：默认关闭、模型参数校验、环境变量白名单、严格JSON、失败结果拒绝、历史过滤/路径边界、loopback只读路由、单次运行与警告失败、开窗失败门禁、取消本实例任务、双流限额、超时/取消父子清理和真实stdio MCP工具发现。
