# 对等协作机制

## 双方的发言权

0.3把协作固定为“客户端先提交方案，模型审阅，客户端最终取舍”，仍是单向委托。0.4新增 `peer-v1` 任务：任一方都可先开题、提问、提出方案、反驳、补证或修正自己。创建后可立即把话轮交给模型，不必先提供客户端方案。

客户端具有本地执行与测试能力，模型伙伴提供独立推理。这是能力分工，不代表谁的判断天然优先。为兼容既有接口，内部来源键仍为 `lead` / `reviewer`、职责参数仍为 `lead_brief` / `reviewer_brief`；页面直接显示 GPT 和实际记录的请求模型名称，例如 Gemini 或 Claude。完整请求标识保留在消息详情中；缺少模型记录时明确显示“未记录模型”。GPT 标签表示客户端提交来源，不是身份认证。旧任务保留原协议，不被改写成新的对等交流。

CLI模型不能自行调用此MCP，客户端仍负责调度话轮。`agy_discussion_turn` 的 `instruction` 可省略，表示轮到对方自行选择发言内容。没有后台无限聊天，每次模型尝试都必须显式发起。

## 如何接住对方

客户端看到对方的问题后，应先作答或质疑其前提，说明证据，再提出自己的补充；不应绕过对方的问题另起一份评审要求。修正观点时明确指出原判断、改动及依据。缺少证据时保留未知和分歧，不编造一致结论。

- `question`：客户端向伙伴提出一个问题，最多800 UTF-16单位。
- `answer`：客户端回应模型伙伴的问题，必须用 `reply_to` 指向对方问题消息。
- `challenge`：对方的前提或建议值得质疑，保留理由与引用。
- `revision`：明确修正自己此前的判断。
- `proposal` / `feedback`：其他方案、事实或反馈。
- `decision`：客户端自己作出取舍，需引用、理由和 `accepted` / `rejected` / `deferred`；不代表模型认可。
- `summary`：归档当前讨论，未解决问题仍保留并显示。

模型伙伴每轮提供：

```json
{"message":"本轮公开发言","question":"希望对方回应的一个具体问题，或null","answers_to":[已明确回应的客户端问题消息编号]}
```

上例的 `question` 无问题时使用 JSON `null`。只把合法的对方问题引用登记为已回应；“已回应”也不代表提问方接受答案。兼容整个回复的JSON代码围栏和一层JSON字符串转义。其他非结构化或不符合约定的回复仍保留原文并提示未提取关系，不推断问题已解决。完整原始回复与CLI来源可在关联 `run_id` 查询，工具另返回解析后的 `contribution`。

## 共享上下文

问题与发言的本地存储是依据，不允许模型输出整场状态并覆盖历史。下一轮保留指定引用、最近3条取舍和最近6条消息；新协议每条发言摘录最多500 UTF-16单位。最多带入4个完整待答问题，先保留指定引用，再按原始顺序选取；其他问题编号列入 `question_ids_omitted`，原文继续留在任务中。双方可通过显式引用切换本轮处理的问题，不自动把延期或沉默归类为冲突。

目标最多2000单位、双方专长各500、本轮额外要求2000、客户端普通笔记4000。总提示上限16000，超过时拒绝该次尝试，不偷偷加窗口。一个任务最多40条消息、1–8次模型尝试（默认4）；任务文件读写上限2 MiB。单条模型发言摘录最多8000单位，完整原文仍在关联运行中。

## 失败、恢复与存储

创建、写笔记、读取、恢复不调用模型；只有交接话轮会启动一次请求。禁用执行不占次数，保留尝试后失败或取消也计入，不自动重试或退回额度。运行期间同一任务不能追加笔记或启动另一次调用，避免双方依据悄悄改变。

用 `agy_cancel(run_id)` 取消本实例的活动调用。中断后可用 `agy_discussion_recover` 对齐关联调用的真实终态，或从已成功的原始回复重新提取可识别的JSON格式；活动或尚无终态的调用会拒绝恢复，不能猜测已结束。保存失败的讨论也可从核对过关联的成功运行恢复，保留失败审计。短写操作使用操作系统锁，进程退出后自动释放；当前协议的残留标记可在取得锁后回收，未知旧锁保留人工检查。具体步骤见[升级与异常恢复](configuration.md#升级与异常恢复)。建议一个状态目录由一个MCP实例管理，实例并发限制不是跨实例全局计费锁。

`<state>/discussions/<id>.json` 与 `<state>/runs/<id>/` 都保存明文私有材料，不上传GitHub。HTTP仍仅loopback只读，不提供执行/写入端点。客户端提交身份未经认证，职责提示不是强制权限隔离。

离线演示标为模拟，真实双方交流记录仅留本地。归档不代表共识、代码完成或验证通过。
